## Struktura repo

```
references/        zdjęcia referencyjne (.jpg, .png)
  Exteriors/       całe budynki: przód, bok, tył, narożniki
  Walls/           ściany i fasady
  Roofs/           dachy
  Windows/         okna
  Doors/           drzwi
  Balconies/       balkony
  Stairs/          schody
  Details/         obramowania, filary, fundamenty
  Materials/       cegła, tynk, beton, rdza, brud, mech, zniszczenia
  Props/           kable, rury, klimatyzatory, szyldy, neony
team-members/      pliki członków zespołu
```

## Jak pracujemy

1. Każdy pracuje na swojej gałęzi (`dawid`, `maja`, `maria`, `zuza`).
2. Przed pracą: w GitHub Desktop **Branch > Update from main**.
3. Commit i push na swoją gałąź.
4. Pull request do `main`.

Pliki Unreal (`.uasset`, `.umap`) i source art (`.fbx`, `.psd`, `.tga` i inne) idą przez Git LFS, ustawiony w `.gitattributes`.

## Referencje: checklista

- [x] Folder `references` z podfolderami kategorii
- [ ] Razem co najmniej 20 do 40 zdjęć `.jpg` / `.png` dobrej jakości
- [ ] Całe budynki z zewnątrz: przód, bok, tył, narożniki
- [ ] Okna, drzwi, dachy, obramowania, filary, schody, balkony, fundamenty
- [ ] Materiały i zużycie: cegła, tynk, beton, rdza, brud, mech, zniszczenia
